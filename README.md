# AdhanBox — distribution

Ce dépôt sert le fonctionnement des boîtiers AdhanBox et de leur application :

- le site [adhanbox.fr](https://adhanbox.fr) (dossier `docs/`) ;
- les mises à jour des boîtiers (`firmware_version*.json` et leurs binaires signés) ;
- le manifeste et les voix téléchargés par les boîtiers (`audio_content.txt`, `catalogue_audio.json`, `audio/`) ;
- l'application Android sans compte Google, dans les [releases](https://github.com/adelhanifiOne/adhanbox/releases).

Le code source n'est pas ici. Le contenu est publié automatiquement : les modifications
directes de ce dépôt ne sont pas acceptées.
